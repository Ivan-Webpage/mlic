# Mlic

本專案由 [Angular CLI](https://github.com/angular/angular-cli) 版本 15.2.8 產生。

## 開發伺服器

執行 `ng serve` 啟動開發伺服器，然後開啟瀏覽器連到 `http://localhost:4200/`。當你修改任何原始碼檔案時，應用程式會自動重新載入。

## 產生程式碼骨架

執行 `ng generate component component-name` 可以產生一個新元件，也可以使用 `ng generate directive|pipe|service|class|guard|interface|enum|module` 產生其他類型的程式碼。

## 建置（Build）

執行 `ng build` 建置專案，建置產物會輸出到 `dist/` 目錄底下。

## 執行單元測試

執行 `ng test`，透過 [Karma](https://karma-runner.github.io) 執行單元測試。

## 執行端對端（e2e）測試

執行 `ng e2e`，透過你選擇的平台執行端對端測試。使用這個指令前，需要先加入一個實作端對端測試功能的套件。

## 更多說明

想取得更多 Angular CLI 的說明，可以使用 `ng help`，或參考 [Angular CLI 總覽與指令參考](https://angular.io/cli) 頁面。
